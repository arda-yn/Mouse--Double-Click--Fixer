Mouse Fixer

is a tool made with AHK (AutoHotkey) to
ignore clicks below a certain speed.

For mice with double-click problems, it is
used to solve the problem software-wise.

---

If you want to change the minimum speed click
threshold, open the .ahk extension file with a
text document file (.txt). Change the number in

"A_TimeSincePriorHotkey < 120"

to the number you want and save it.
Then, download the AutoHotkey and open
your edited .txt file with this software.

It is not recommended to set this value to ~1000 or higher.

---

There is actually no guide here. Threshold is
set to a good value, so it shouldn't cause a problem.

ALL you need to do is run .exe file and see the magic.
